# Global Freelancer Analysis

## Project Overview
This project analyzes a global freelancer dataset using Excel and Power BI.

## Objectives
- Analyze freelancer distribution by country.
- Compare active and inactive freelancers.
- Study freelancer experience levels.
- Analyze hourly rate and experience.
- Understand gender and language diversity.

## Tools Used
- Microsoft Excel
- Power BI
- DAX

## Key Insights
- Countries with higher freelancer counts represent strong talent markets.
- Comparing active and inactive freelancers helps identify workforce engagement.
- Experience level provides insights into the freelancer workforce.
- Hourly rate can be compared with years of experience to identify pricing patterns.
